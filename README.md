# 特效台 · Windows 发布通道

本仓库用于软件版本说明、安装程序和签名更新清单，不存储用户工程、导入的照片/视频、开发源码或发行私钥。

## 当前状态

发布仓库已建立。Windows 本机安装版本和仅更新时联网的客户端模块正在验证整理；本仓库尚未发布可公开下载的安装程序。

在公开提供二进制前，需要完成所含第三方组件的对应源码提供安排，并核对内置设计资源的分发授权。当前不放置占位安装链接，也不将未发布的版本标为可下载更新。

## 后续更新方式

正式发行将在 Releases 中发布版本化安装文件和由发行者签名的更新清单。客户端核对签名、长度及文件摘要后才允许安装，更新前须保存工程并回到项目库。

正常编辑、预览与导出均在本机完成。仅检查或下载更新时需要联网，断网不阻断已有功能。
